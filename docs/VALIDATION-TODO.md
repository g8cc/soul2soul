## 维护约定

1. 修改 ICE、音频、视频采集/渲染、屏幕映射或电量相关代码后，确认受影响的场景 ID；新增风险就在表中增加条目。
2. 单测、协议测试通过只能更新软件测试状态，不能把对应真机项勾为完成。
3. 只有记录了版本、设备、步骤和结果的真机证据后才更新状态；失败时转为明确缺陷并补回归用例，修复后重跑相关场景。
4. 新版本发布或关键媒体链路改动后，重新确认哪些证据仍适用于当前版本，不把旧版本结果直接沿用为新版本通过。
