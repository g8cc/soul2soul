## A. 需要你回答的问题（按重要性排序）

1. **【一票否决项】她的华为手机是不是 HarmonyOS NEXT（纯血鸿蒙）？**
   NEXT 不能运行安卓 APK，整个方案对她的手机失效。
   查法：设置 → 关于手机 → 看"HarmonyOS 版本"。**2.0~4.x = 安卓版，OK；5.0/NEXT = 不行**。
   如果真是 NEXT：备选①她用旧安卓机陪玩；②长期再看要不要做跨端（成本翻倍，需重新立项）。

2. **服务器**：`ssh guo` 指向的机器——公网 IP 是多少？我部署时会自动探测，但请确认：
   - 云厂商**安全组**（控制台里的那个，不是机器本身防火墙）是否可放行：`8080/TCP`、`3478/UDP+TCP`、`49160-49200/UDP`。安全组如果在控制台，我改不了，需要你点一下。
   - 机器配置大致多少核/多少带宽？（TURN 中继峰值约 2.5Mbps，1 核 1M 的轻量服务器跑得动信令但中继会顶满带宽，需要知道）

3. **域名与 HTTPS**：有没有现成域名（已备案）指向这台服务器？
   - 有 → v1 就上 `wss://`（信令加密）。
   - 没有 → 先用 `ws://IP`（不上架自用可接受，SPEC §7 有升级路径）。

4. **App 名称与图标**：暂定「Soul2Soul」，中文名暂定「陪着你」。图标暂定粉色爱心。要改直接说。

5. **标注默认形态**：默认做成"激光笔"（松手 2 秒消失，防画花屏幕）。要不要同时支持"持久涂鸦"模式？我排到 v1.1 了，你如果觉得更重要就提前。

6. **呼叫不在线时**：v0 只提示"对方不在线"。要不要做"漏接来电"补发提醒（打开 App 时显示"TA 在 23:47 想过你"）？我排在 P2，可提前。

7. **锁屏自动结束**：共享端锁屏 30 秒无画面 → 自动结束会话。这个防挂死策略 OK 吗？

8. **UI 语言**：全中文，OK？

## C. 我替你做的技术决定（可否决，默认执行）

| # | 决定 | 理由 / 影响 |
|---|---|---|
| C1 | 信令服务器用 Node.js + `ws`，JSON 协议 | 服务器上零依赖部署；协议文档化在 SPEC §2，以后想换 Go/Java 重写也只需对齐协议 |
| C2 | TURN 用 coturn（优先 Docker，没有 Docker 就 apt 装） | 自建 WebRTC 的标配兜底，国内移动网络 P2P 成功率低 |
| C3 | libwebrtc 用预编译 AAR `io.getstream:stream-webrtc-android:1.1.1` | 自编译 libwebrtc 需要 100GB+ 磁盘和数小时，不值；API 就是官方 `org.webrtc.*` |
| C4 | minSdk 29（Android 10） | 两台目标机都远高于此，砍掉一堆旧系统兼容代码 |
| C5 | UI 用经典 View 而不是 Compose | 悬浮窗标注层必须是 View；全 App 统一技术，骨架期最不容易踩坑 |
| C6 | 无账号体系：deviceId(UUID) + 6 位配对码 | 恋人场景够了，省掉注册登录和短信费用 |
| C7 | 在线待命 = 常驻前台服务（低优先级通知） | 不接厂商推送前的唯一可靠方案；需要你俩手动开白名单（App 内有引导） |
| C8 | v0 信令走明文 `ws://IP`，v1 升 `wss` | 家庭场景风险可控；有域名后 30 分钟能升级 |
| C9 | TURN 凭证 = HMAC 时限凭证（1 小时有效） | 静态密钥不泄露的前提下，凭证被截获也只有 1 小时窗口 |
| C10 | 配对关系存服务器 `data/pairings.json` | 两人量级不需要数据库；文件备份即可 |
| C11 | 屏幕采集 720p@30 起步，长边≤1280 | 流量/发热/画质平衡点；libwebrtc 码率自适应兜底 |
| C12 | 标注走 WebRTC DataChannel（不走信令） | 端到端延迟最低，不经过服务器 |
