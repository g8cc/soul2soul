# Soul2Soul 需求文档（PRD）

## 1. 一句话定位

给异地恋人的「陪伴按钮」：想念对方时一键召唤，把自己的手机屏幕实时共享给 TA；
TA 能看着你的画面实时说话，还能用手指在你的屏幕上画圈圈指出"这里可以消冰块"——
像 TA 就坐在你旁边一起玩手机一样。

## 2. 目标用户与前提

- **固定两人**：一对恋人，各持一台安卓手机（小米 + 华为，均为新款，详见 A1 风险）。
- 不上架，APK 侧载；双方都在国内网络环境。
- App 内是唯一绑定关系（配对），没有陌生人、没有社交功能。

## 3. 核心场景（用户故事）

**S1 召唤**
晚上 10 点，我想她了。打开 App，点一下大大的「一起玩」。她手机弹出全屏呼叫，像来电话一样。
她点「接受」。

**S2 陪玩**
她接通后，我把屏幕授权给 App，然后切到消消乐照常玩。她那边全屏是我的游戏画面，
延迟不到半秒，我们开着语音像打电话一样聊天。

**S3 指挥**
她看到右边有一排冰块，用手指在我的画面上画了个圈，说："先消这里！"
我玩游戏的同时，红色的圈圈浮现在我的屏幕上，2 秒后淡去。

**S4 角色互换**
她想给我看她刚拍的猫。她发起共享，这次换我看她的屏幕、给她画圈圈。方向反过来而已。

**S5 结束与告别**
打完这关，她点了挂断（或者我点屏幕上的小气泡）。两边同时回到待命页。
没有任何东西被录制、被保存——像挂掉一个电话。

## 4. 功能需求

优先级：P0 = 第一版必须有；P1 = 第二版；P2 = 加分项。

### P0

| 编号 | 需求 | 说明 |
|---|---|---|
| FR-1 | 配对绑定 | 首次使用：A 生成 6 位配对码（10 分钟有效），B 输入即绑定；持久化，重装 App 后用同一 deviceId 自动恢复关系（重装换 deviceId 需重新配对） |
| FR-2 | 待命与呼叫 | 常驻轻量在线（前台服务+白名单引导）；呼叫后对方弹**全屏来电式界面**（响铃/震动）；30 秒未接自动取消并提示 |
| FR-3 | 屏幕实时共享 | 720p@30 起步，自动码率；观看端按比例 letterbox 全屏显示 |
| FR-4 | 双向语音 | 双方麦克风互通，回声消除，默认扬声器外放 |
| FR-5 | 画笔标注（激光笔） | 观看端手指滑动即画，**本地 0 延迟显示**；共享端以悬浮层浮现对应笔迹，2 秒淡出；3 种颜色可选 |
| FR-6 | 共享端悬浮控制 | 全屏不可触摸标注层（不挡游戏操作）+ 可拖动小气泡：结束按钮 |
| FR-7 | 结束会话 | 三个入口：共享端气泡 / 观看端挂断按钮 / 双方通知栏；任一端结束，双方退出 |
| FR-8 | 容错 | 对端失联（进程被杀/断网）≤15 秒自动结束并提示；共享端锁屏 30 秒无画面自动结束；网络切换触发 ICE 自动恢复 |
| FR-9 | 权限与白名单引导 | 首次运行一次性引导：通知、麦克风、悬浮窗、屏幕录制；小米（自启动/省电无限制/后台弹出界面）与华为（启动管理手动）专项引导页 |

|---|---|

| FR-11 | 持久文字标注（打字上屏，替代涂鸦沟通复杂信息） |
| FR-12 | 语音静音开关（单向听） |
| FR-13 | 漏接来电补发："TA 在 23:47 想过你" |
| FR-14 | 信令升级 wss/TLS |

### P2（M3）

|---|---|

| FR-16 | 游戏声音共享（Android 音频采集） |
| FR-17 | 厂商推送保活（MiPush/HMS） |
| FR-18 | 画笔多颜色/粗细、共享端静音气泡 |

## 5. 非功能需求

| 编号 | 指标 |
|---|---|
| NFR-1 延迟 | 同城宽带 P2P 端到端 < 400ms；TURN 中继 < 800ms；语音端到端 < 300ms |
| NFR-2 画质 | 默认 720p；带宽不足时 libwebrtc 自动降码率/帧率，画面文字可辨认 |
| NFR-3 隐私 | 媒体 DTLS-SRTP 加密；**零录制零存储**；会话结束即焚 |
| NFR-4 可靠性 | 待命连接被杀后，打开 App 2 秒内重连；呼叫打通率优先于一切 |
| NFR-5 电量 | 待命态耗电 < 2%/小时；共享态接受较高耗电（编码+上行是本质成本） |
| NFR-6 安全 | 只允许已配对设备互相呼叫；TURN 凭证 1 小时时限 |

## 6. 验收标准（P0 全部满足才算 M0+M1 完成）

- AC-1 两台全新手机，从安装到完成首次呼叫 ≤ 10 分钟（配对码流程顺畅）。
- AC-2 观看端看消消乐：画面流畅、游戏内文字清晰可辨、语音无明显回声。
- AC-3 观看端在冰块处画圈 → 共享端对应位置浮现笔迹 ≤ 2 秒，位置偏差 ≤ 画面宽度 5%。
- AC-4 任一端点结束 → 双方 3 秒内回到待命页，可立即再次呼叫。
- AC-5 观看端开飞行模式 → 共享端 15 秒内收到断线并自动结束，状态正确。
- AC-6 共享端锁屏 → 30 秒后双方自动结束。
- AC-7 杀掉 App 进程重新打开 → 配对关系仍在、能收到呼叫。

## 7. 明确不做（Non-goals，变动需重新评审）

- ❌ 远程直接操作对方手机（无障碍注入点击）
- ❌ 录制/回放会话内容
- ❌ 多人房间、好友体系、任何社交功能
- ❌ 账号注册/登录（配对码即身份）
- ❌ 应用商店上架、iOS 版本
